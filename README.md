
This work started following the excellent tutorial at https://github.com/jameshibbard/node-htmx


initialise and setup tooling

```bash
npm init -y

npm install express
npm install -D typescript @types/node @types/express ts-node nodemon
```


transpile and run
```bash
npm run build
node ./dist/server.js
```
